# backup/ —— 备份标定证据

本目录在本轮重组后**暂为空**，保留它是为了让 `docs/evidence/` 的分类与
[恢复演练与对账口径](../../runbooks/恢复演练与对账口径.md) 的叙述一一对应。

为什么没有文件：

- 备份与恢复的**原始数据**是 8 次恢复演练的逐次台账与汇总
  （`tdengine_restore_drill_*.json`），它们记录的是"恢复"这件事，按归档判据归
  [`../drill/`](../drill/)；
- 备份**产物与台账**（`manifest.json`、`LATEST.json`、`logs\backup_log.jsonl`）按设计落在
  仓库外 `F:\cems-backup\`（见 [ADR-0005 §1.5](../../adr/0005-备份策略与保留期.md)），
  体积原因不入库，只在文档里被引用。

若将来新增独立的备份标定产物（例如备份耗时/体积的逐次采样），放这里。
