# 工程事实：容器虚拟时钟相对宿主机存在漂移（2026-10-01 实测）

> **⚠️ 这条影响所有跨容器/跨宿主机的时间测量，必须先读再测延迟。**
> **发现人**：`metrics-lab`（task-7 测端到端延迟时的前置核查）
> **状态**：已由外部基准（NTP）复核，结论成立。
> **⚠️ 不要动这个结论，也不要把它当成"配置没对齐"去修** —— 见文末。

---

## 1. 现象（实测数据）

| 核对项 | 实测结果 |
|---|---|
| **容器之间** | 五个容器共享同一 `CLOCK_REALTIME`，两两偏差 **P50 1~9 ms** → 容器之间**基本同步** |
| **容器 vs 宿主机** | ⚠️ **不是同一个时钟** |
| 偏移形态 | **锯齿波**：45 秒内从 **−352 ms** 摆到 **+471 ms**，连续段斜率 **−26 ms/s（≈ −26000 ppm）**，并周期性向前跳变 **+300~+820 ms** |
| 外部基准 | 用 NTP 确认真值：**宿主机时钟 45 秒内相对真值稳定（极差 18 ms）** |
| 判定 | ⭐ **是容器的虚拟时钟在漂，不是宿主机** |

**校正措施（已执行）**：所有延迟数字都按同期 `SELECT NOW()` 做了**逐样本时钟校正**；
**未校正前的毫秒级结论不可引用**。

---

## 2. 为什么会这样（机理，写清避免后人误判）

Docker Desktop on Windows 的 Linux 容器跑在虚拟机里，虚拟机时钟由宿主机的 Hyper-V/WSL 时间同步机制定期校正，
表现为"**慢慢漂 → 被拉回**"的锯齿。这与 `TZ: Asia/Shanghai` 这类**时区**设置完全无关——
时区只决定"显示成几点"，不决定"时钟走得准不准"。**设置 TZ 不能解决漂移。**

**⭐ 因此：**
- **秒级**判断（例如"ts 是不是北京时间""两条数据间隔 5 秒"）**不受影响** —— 所以之前核对 `date` 和同一行 `ts` 都一致，结论仍然成立。
- **毫秒级**测量（端到端延迟、抖动）**必须先校正**，否则测到的是时钟漂移，不是系统延迟。

## 3. 对项目里各处的具体影响

| 场景 | 是否受影响 | 说明 |
|---|---|---|
| 端到端延迟（设备→库） | 🔴 **严重** | 必须逐样本用 `SELECT NOW()` 校正，或用**同一时钟**下的两个时间点相减 |
| 采样的时间间隔（5 秒/条） | 🟢 不受 | 秒级；且间隔由 `POLL_INTERVAL` 决定 |
| 数据完整率（按小时计） | 🟢 不受 | 小时是秒级尺度 |
| 对账（源端/库内计数） | 🟢 不受 | 只比条数 |
| 日志时间与库内 ts 对齐 | 🟡 注意 | 秒级一致；**别拿毫秒位做因果推断** |
| 之前的"三条路径时间一致"结论 | ✅ **仍然成立** | 那条是秒级核对（见 `docs\告警判据设计.md` §3.6） |

---

## 4. ⚠️ 不要把这条当"配置问题"去修

- ❌ 不要试图通过改 `TZ`、改 compose、重启容器来"修"它——**它不是配置错**，是虚拟机时钟的固有行为。
- ❌ 不要为了"让两条路径一致"而给某个服务加人为偏移——那会在别的场景引入新的错。
- ✅ 正确做法：**测量时校正**（逐样本对基准），**并在文档里写明校正方法**。
- ✅ 真要做到毫秒级精确，得换测量手段（例如：让产生方与接收方**使用同一个时钟源**打点，
  而不是各自读自己的时钟再相减）。

## 5. 复现方法

```powershell
# ① 容器之间（应基本同步）
foreach ($c in @("cems-device","cems-gateway","cems-subscriber","cems-web","tdengine","emqx")) {
  "$c : " + (docker exec $c date "+%Y-%m-%d %H:%M:%S.%N")
}

# ② 容器 vs 宿主机（应能观察到锯齿漂移；多采几次看得更清楚）
1..20 | ForEach-Object {
  $h = Get-Date
  $c = docker exec cems-web date "+%Y-%m-%d %H:%M:%S.%N"
  "$($h.ToString('HH:mm:ss.fff'))  vs  $c"
  Start-Sleep -Milliseconds 2000
}
```

**判读**：若容器与宿主机的偏差**持续单向增大再突然拉回**，即复现本条；
若只是固定偏移（常数），那是别的问题（例如时区设错）。
