## 二、测试目标

验证从设备层（Modbus 寄存器）→ 网关层（解码/缓存/MQTT发布）→ 消息层（EMQX）→ 接入层（订阅/解析）→ 存储层（TDengine 入库）的**全链路数值传递一致性**，确保：
1. 8 个测点的数值在传递过程中无精度丢失
2. SCALE=10 缩放正确（寄存器存 ×10 整数，入库还原为真实值）
3. 列对应正确（so2/nox/flow/dust/o2/temp/humidity/pressure 无错位）
4. 时间戳间隔与网关轮询间隔一致（5 秒）

## 三、通过标准（全部满足才算通过）

1. 设备输出固定值后，TDengine 中最近 N 条数据的 8 个测点值**全部等于**预期固定值
2. 数值精度与 points.py 定义一致（如 O2=8.5 不是 85 也不是 8）
3. 时间戳间隔为 5 秒 ±1 秒，无跳变、无重复
4. 无脏数据（重启切换点前后数据清晰，无半写状态）
