## 二、测试目标

验证从设备仿真（Modbus TCP）→ 网关采集 → MQTT传输 → 平台订阅 → TDengine入库的全链路数据一致性，确保：
1. 8个测点数值在全链路传递中无精度丢失
2. 测点列对应正确，无列错位
3. SCALE=10缩放正确
4. 时间戳间隔正确（5秒/条）

## 三、整体通过标准

全部用例PASS才算通过：
1. 8测点数值 = 预期固定值，误差 < 0.01
2. 时间戳间隔 = 5秒，误差 < 0.5秒
3. 无列错位（so2列存的是so2值，不是nox值）
4. 测试后恢复随机值，环境干净
