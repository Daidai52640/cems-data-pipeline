## 1. 这个版本是什么

**CEMS 数据采集链路**：仿真设备 → 网关 → MQTT → 平台接入 → TDengine → Web 展示，
**加上运维与可靠性配套**（Nginx/Redis/日志上限/备份恢复/故障台账）。

```
设备(Modbus 仿真) → 网关(轮询+断网续传) → EMQX → 接入层(校验+折算) → TDengine → Web/报表
                        │                                                  │
                   Nginx 反代 ─┘                         Redis 缓存(仅已闭合窗口) ─┘
```

**服务规模**：8 个容器（device / gateway / subscriber / web / nginx / redis / emqx / tdengine），全部带健康检查。

### 2.5 已知边界（**必须知道，别过度声明**）
| # | 边界 |
|---|---|
| 1 | ⚠️ **报文体是内部简化格式**（`"时间戳 测点=值 … Flag=N"`，走 MQTT），**不是 HJ 212 报文**；对环保平台的 HJ212 出口属**预留能力** |

| 6 | ⚠️ **备份未挂定时调度**，目前靠人跑（国标要求"应自动备份"） |
